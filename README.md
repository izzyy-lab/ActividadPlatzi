# Actividad Colaborativa - GitFlow

## Descripción

Este proyecto fue desarrollado como una actividad colaborativa con el objetivo de aprender y poner en práctica la metodología **GitFlow** utilizando **Git** y **GitHub**.

La actividad consistió en realizar una copia del sitio web de **Platzi**, distribuyendo el trabajo entre los integrantes del equipo mediante ramas de desarrollo y posteriormente integrando los cambios al proyecto principal siguiendo el flujo de trabajo de GitFlow.

## ¿Qué es GitFlow?

GitFlow es una estrategia de trabajo para el control de versiones que organiza el desarrollo mediante diferentes ramas, facilitando el trabajo colaborativo y el mantenimiento del proyecto.

Las ramas más utilizadas son:

- **main:** Contiene la versión estable del proyecto.
- **develop:** Reúne los cambios que se encuentran en desarrollo.
- **feature:** Se utiliza para desarrollar nuevas funcionalidades de forma independiente.
- **release:** Preparación de una nueva versión del proyecto.
- **hotfix:** Corrección rápida de errores en producción.

Gracias a este flujo de trabajo, varios desarrolladores pueden trabajar simultáneamente sin afectar la estabilidad del proyecto.

## Objetivo de la actividad

- Comprender el funcionamiento de GitFlow.
- Practicar el trabajo colaborativo utilizando Git y GitHub.
- Aprender a crear, fusionar y administrar ramas.
- Resolver conflictos durante la integración del código.
- Desarrollar una copia del sitio web de Platzi aplicando buenas prácticas de control de versiones.

## Tecnologías utilizadas

- HTML5
- CSS3
- Git
- GitHub

## Resultado

Al finalizar la actividad, el equipo logró integrar correctamente los cambios realizados por cada integrante utilizando GitFlow, fortaleciendo el conocimiento sobre el manejo de ramas, la colaboración en proyectos y el uso de Git como sistema de control de versiones.
